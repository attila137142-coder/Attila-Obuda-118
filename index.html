🚍 Attila Közlekedés V5 Architecture

Valós idejű országos közlekedési rendszer – GTFS alapú integráció

1. Áttekintés

A V5 rendszer egy egységes közlekedési platform Budapest és Magyarország környékére, amely valós idejű járműkövetést, menetrendi adatokat és intelligens keresést biztosít.

GTFS Real-time Dispatcher

2. Adatforrások

  • BKK (Budapest)
  • MÁV (vasúti hálózat)
  • Volánbusz (távolsági és regionális)
  • HÉV hálózat
  • Erdészeti és kisvasutak (Börzsöny, Pilis, stb.)

3. Fő modulok

  • 🔎 Unified Search Engine – megálló és járat kereső
  • 🗺️ Dispatcher Map – élő járműkövetés
  • 🚦 Real-time Tracking – FUTÁR-szerű rendszer
  • 🚏 Stop & Route Info – részletes menetrend
  • ⚙️ API Layer – egységes adatkezelés

4. Rendszer architektúra

  • Frontend: React dashboard (Vercel deploy)
  • Backend: Node.js / serverless API
  • Adatfeldolgozás: GTFS parser + normalizáció
  • Realtime: WebSocket / polling hibrid

5. Adatmodell

Egységesített objektumok: járművek, vonalak, fordák, megállók, események és valós idejű pozíciók.

6. Deployment (Vercel)

  • GitHub integráció
  • Automatikus deploy
  • Edge API functions
  • Gyors iterációs fejlesztés

7. Roadmap

  • V5 stabil backend
  • Teljes BKK GTFS import
  • MÁV integráció
  • Valós idejű térképes optimalizáció
  • Országos skálázás

8. Cél

Egy FUTÁR-szerű, de országos és bővíthető intelligens közlekedési rendszer, modern dashboard felülettel és valós idejű adatfeldolgozással.
