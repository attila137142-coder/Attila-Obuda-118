Közös, interneten elérhető PDF-lista: a ténylegesen a GitHub KOZOS_TARHELY mappájába feltöltött PDF-eket keresi, almappákkal együtt. Windows 10-en GitHub Desktopból vagy a GitHub weboldalán tölthetsz fel; iPhone-on a PDF megnyitható és a Fájlok közé menthető.
🔒 ADATVÉDELMI FIGYELMEZTETÉS
Ide kizárólag nyilvánosságra hozható PDF-et (például menetrendet, közlekedési tájékoztatót) tölts fel. Kórházi leletet, egészségügyi dokumentumot, bankszámlakivonatot vagy más személyes iratot ne tegyél nyilvános GitHub-tárba. Ezekhez privát, bejelentkezést igénylő tárhelyet használj.
📘 RÉSZLETES ÚTMUTATÓ – feltöltés, letöltés, törlés
1. A közös mappa létrehozása (egyszer kell)
  1. Nyisd meg a „GITHUB MAPPÁK” gombot, majd a repository főoldalát.
  2. Válaszd az Add file → Create new file lehetőséget.
  3. A fájlnév mezőbe írd: KOZOS_TARHELY/MENETRENDEK/README.md.
  4. A tartalomba írj például ennyit: Nyilvános közlekedési PDF-ek., majd Commit changes.
  5. Ha más kategória kell, hozz létre további almappát ugyanígy: TERKEPEK, FORGALMI_MUNKALAPOK vagy BELSO_INDITASI_JEGYZEK.
2. Feltöltés Windows 10-en – GitHub Desktop
  1. Nyisd meg a helyi repository-mappát a Fájlkezelőben.
  2. Nyisd meg a KOZOS_TARHELY megfelelő almappáját. Ha még nincs, hozd létre.
  3. Másold vagy húzd be a PDF-et a mappába.
  4. GitHub Desktopban ellenőrizd a változásokat, írj rövid üzenetet (például PDF feltöltés), kattints Commit to main, majd Push origin.
  5. Az alkalmazásban kattints a KÖZÖS TÁR FRISSÍTÉSE gombra.
3. Feltöltés a GitHub weboldalán
  1. Nyisd meg a repositoryt, majd a KOZOS_TARHELY célmappát.
  2. Add file → Upload files.
  3. Válaszd ki vagy húzd be a PDF-et, majd kattints Commit changes.
  4. Frissítsd a PDF-listát az alkalmazásban.
4. Megnyitás és letöltés iPhone-on
  1. A közös PDF-listában nyomd meg a MEGNYITÁS gombot.
  2. A megnyílt PDF megosztás menüjében válaszd a Mentés a Fájlokba lehetőséget, ha helyben is szeretnéd tárolni.
  3. A telefon helyi tárába mentett PDF nem kerül vissza automatikusan a GitHubra.
5. Törlés (óvatosan)
  1. GitHubon nyisd meg a PDF-et, majd a fájl menüjében válaszd a törlést (Delete file).
  2. Commitold a törlést; GitHub Desktop esetén a helyi fájl törlése után Commit, majd Push szükséges.
  3. A listát frissítsd. A GitHub előzményeiből való végleges eltávolítás külön művelet lehet.
Fontos: ez a panel nyilvános GitHub-fájlokat listáz és nyit meg. Nem tartalmaz titkos feltöltési tokent, ezért nem tud közvetlenül feltölteni vagy törölni a GitHubon. A GitHub-tárhely méret- és fájlméretkorlátai miatt nagy PDF-gyűjteményhez nem ideális.
